# Defect Detector

Простой детектор дефектов изображения.

Скрипт анализирует PNG-файл и определяет, является ли изображение нормальным или содержит дефект.

## Логика

Если красный цвет занимает более 10% изображения, результат считается `DEFECT`. В остальных случаях результат — `OK`.

Модель машинного обучения не используется: это прототип, который демонстрирует принцип computer vision — изображение → поиск красных пикселей → порог → классификация.

## Установка

Требуется Python 3. Установите зависимость:

```bash
python3 -m pip install -r requirements.txt
```

## Запуск

Проверка нормального изображения:

```bash
python3 detector.py images/ok.png
```

Результат: `OK`.

Проверка изображения с дефектом:

```bash
python3 detector.py images/defect.png
```

Результат: `DEFECT`.

## Тестовые изображения

- `images/ok.png` — нормальное синее изображение;
- `images/defect.png` — синее изображение с большой красной областью, имитирующей дефект.
